# 重构后细节自查

本轮沿用已确认设计，不更换方向。使用 frontend-quality-loop、ui-ux-pro-max 和 vercel-react-best-practices，从交互、信息真实性、键盘、响应式和主题五个角度检查。

## 已修正

1. 收件箱：去掉假复选框；桌面点击任务切换右侧预览，并显示选中态；手机保持直接打开详情。“整理”仍可编辑。空说明使用引导文案。移动操作加防重复提交，成功后立即移除对应行。
2. 搜索：编辑窗口打开时不再叠加搜索或把焦点送到浏览器地址栏；方向键可进入结果，结果补充项目上下文；提供加载播报、空结果播报和读取失败重试。
3. 提醒准确性：今天页同时考虑缺少可执行任务的项目，不会在有项目问题时显示“没有需要处理的提醒”。
4. 布局细节：手机导航居中；短屏侧栏隐藏金句且可滚动，保留设置入口；项目提醒动作和箭头不再断开；记录按钮的说明与标题分开，去掉误导的直接保存提示。
5. 深色对比：增加 on-accent 语义令牌，浅蓝主按钮使用深色文字；该组合对比度从约 3.20:1 提高到 5.76:1。

主要文件：InboxPage.tsx、SearchDialog.tsx、ReviewBrief.tsx、App.tsx、shell/tasks/projects/responsive/foundation.css、tokens.css、i18n/index.ts、workspace-search.e2e.ts。
