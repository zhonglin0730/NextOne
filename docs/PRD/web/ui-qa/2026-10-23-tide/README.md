# 任务专注页 · 潮汐融合首版

## 交付与体验

独立开发预览：http://127.0.0.1:5173/focus-preview.html 。使用正式 ZenMode 组件，样例任务仅在内存中展示，不写项目数据。
正式入口：http://127.0.0.1:5173/today ，对进行中任务点“专注”。开发服务保留运行。

设计遵循用户确认的融合方向：自然场景、可选声音、居中计时。主页面信息架构未改动。
采用 frontend-quality-loop、ui-ux-pro-max、vercel-react-best-practices，复用原山湖图片，不新增外部素材服务。

## 改动

- `ZenMode.tsx`：任务名、计时与播放控制分层；项目名作为上下文；说明、继续点和任务状态操作按需展开；保留退出、Esc 与键盘循环。
- `AmbientSound.tsx`、`ambientAudio.ts`：关闭 / 雨声 / 海浪 / 林风，按需创建 Web Audio，滑块调音；暂停渐停、恢复播放、静音挂起、退出关闭。
- `styles/zen.css`：独立维护沉浸样式，移除原任务样式和响应式文件中旧 Zen 规则，避免层叠覆盖。静态自然图片配合可读性遮罩，手机优先纵向操作。
- `tokens.css`：集中增加专注页颜色、遮罩和计时字号令牌。
- `i18n/index.ts`：环境声与交互文案；修正专注累计记录的翻译键位置；“不计时”改为更准确的“自由计时”。
- 提前结束不再按计划 25 分钟记账，实际 65 秒记 1 分钟；任务状态保持独立。
- 开发预览 HTML 未加入生产构建输入；`dist` 中已检查不包含预览入口。

环境声音为程序合成的氛围近似，不是自然实录。首版共用一个山湖背景，尚未提供不同场景的图片切换。
