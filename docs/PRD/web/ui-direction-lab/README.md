# NextOne UI Direction Lab

这是与正式 Web 页面隔离的视觉方向实验，不连接业务数据，也不进入生产构建。

## 七个方向

### A：安静而精确（低风险）

- 中性冷灰背景与清晰纸面层级
- 品牌蓝仅用于主操作、选中状态和少量文字
- 卡片数量克制，项目组合使用列表而非卡片矩阵
- 适合长期使用，迁移现有产品的成本最低

### B：温暖编辑感

- 暖灰纸张色与宋体/衬线标题
- 用版式、文字尺寸和分隔线建立层级
- 更像个人项目日志，弱化软件后台感
- 个性最强，但需要系统性调整全站排版

### A+B：温暖而精确

- 保留 A 的清楚层级、紧凑操作和列表扫描效率
- 吸收 B 的暖纸色、少量衬线标题和个人项目日志气质
- 避免巨型编辑式标题，不牺牲主业务页面的信息效率
- 作为 A 与 B 的折中方向，可直接与两者对照

### C：结构化工作台

- 高对比、低圆角、紧凑网格和结构化标签
- 强调项目控制台和信息扫描效率
- 视觉辨识度高，适合偏专业、偏工具型定位
- 对移动端需要单独设计，不宜直接压缩桌面布局

### D：空间化项目看板

- 让项目任务直接占据主画布，保留 Trello 式拖动与状态直觉
- 不照搬通用四列看板，优先呈现“今日推进 / 下一步 / 等待外部”，已完成折叠为历史摘要
- 今日承诺、下次回顾与 WIP 位于看板上方，不需要跳到另一个仪表盘
- 最适合作为单个项目内部的执行视图，保留 NextOne 最初“个人项目管理而非 Todo”的产品基因

### E：原生三栏工作台

- 左侧项目、中间任务、右侧详情始终同屏
- 选中任务后直接编辑、专注、等待或完成，不再打开抽屉或反复跳页
- 详情顶部保留项目结果与今日承诺，避免退化成纯任务数据库
- 接近成熟桌面应用的连续操作感，减少用户记忆路径
- 当前最适合作为 NextOne 桌面端主骨架；平板和手机需要分别设计双栏与单栏导航

### B+：融合候选

- 用 B 的暖中性色、编辑感字体与纸面分隔统一整套视觉语言
- 用 E 的常驻项目导航、任务画布与详情检查器减少跳页和抽屉
- 用 D 的“今日推进 / 下一步 / 等待外部”项目看板保留空间操作感
- 三者不是并排拼接：B 是视觉系统，E 是信息架构，D 只是中间画布的一种项目视图

本实验首先用于确定桌面端视觉方向，不代表移动端布局方案。小窗口会横向展示完整桌面样张，后续在方向确认后再分别设计 900px 和 390px 断点。

## 共同约束

- 不使用装饰性彩色竖条
- 不使用大面积淡蓝、淡黄、淡绿状态背景
- 不使用无意义渐变和玻璃效果
- 不用卡片套卡片表达所有层级
- 胶囊只保留给真正的筛选器或状态
- 阴影只表示悬浮层或核心表面，不作为默认分隔方式
- 先通过字体、字号、间距、对齐和分隔线建立秩序

## 查看方式

在工作区根目录运行静态服务器后访问：

`http://127.0.0.1:4174/docs/PRD/web/ui-direction-lab/`

页面顶部可切换 A/B/A+B/C/D/E/B+ 与浅色/深色。快捷键 `1` 至 `7` 切换方向，字母 `D` 切换主题。
