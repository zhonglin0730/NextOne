# M8 Android 验收指南

## 1. 准备

电脑上启动当前本地环境：

```powershell
pnpm db:up
pnpm server:run
pnpm mobile:dev
```

Android 手机安装 Expo Go，与电脑处于同一网络，然后扫描 Expo 终端二维码。
如果只验收离线能力，可以不启动数据库和服务端。

## 2. 核心验收

1. 打开“快速记录”，输入标题并保存；
2. 关闭网络，继续记录两项任务；
3. 在“收件箱”逐项打开任务决策，将任务改为“准备就绪”“等待”或“放弃”；
4. 在“今天”的候选列表把准备就绪任务加入今天；
5. 彻底关闭并重新打开应用，确认任务和今天计划仍存在；
6. 恢复网络，观察顶部状态由“待重试”转为“已同步”。

这些页面均为 React Native 原生组件，不依赖 WebView。

## 3. 服务端地址

- Android 模拟器访问电脑本机：`http://10.0.2.2:8080`；
- Android 真机访问电脑：填写电脑局域网 IP，例如 `http://192.168.1.10:8080`；
- Oracle 或生产环境：填写 Caddy 提供的 HTTPS 地址。

在“设置 → 同步与安全”中填写 API 地址和访问令牌。凭据保存在 Android
Keystore 支持的 Expo SecureStore 中，不写入 SQLite 业务库。

## 4. 通过标准

- 断网时快速记录和任务决策可用；
- 应用重启后 SQLite 数据仍存在；
- 应用启动、回到前台、网络恢复时会尝试同步；
- 同步失败只显示状态，不阻断本地操作；
- Web 与 Android 共享 `TaskStatus`、应用服务和 `/api/v1/sync/*` 契约；
- 不使用付费 SaaS、Firebase 或 EAS 云构建。

## 5. 当前不包含

- 签名 APK / AAB 和应用商店发布；
- 推送通知和系统后台常驻同步；
- 标准 OIDC 登录；
- Oracle ARM 生产部署。

以上分别属于发布阶段、后续移动端增强和 M9。
