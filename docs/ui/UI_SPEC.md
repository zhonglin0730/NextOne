# NextOne Web UI 约束

## 产品与界面

- 界面：项目总览、项目推进看板与跨项目“今天”执行切片。
- 用户：独自管理多个长期或阶段性项目的个人用户。
- 首要任务：先看清项目结果和当前卡点，再选择一个可执行下一步并持续推进。
- 成功动作：在项目上下文中开始、完成、等待或安排任务；状态与“加入今天”保持两个维度。

## 方向

- 设计气质：暖中性色、克制蓝色、中文优先；安静但不松散，工具感强但不做后台控制台。
- 保留：NextOne 标志、项目优先的信息架构、项目结果、三段执行看板、可访问的按钮路径。
- 避免：暗黑科技默认风格、霓虹色、玻璃拟态、无意义渐变、所有内容卡片化、彩色左侧装饰条。
- 层级：项目结果与当前行动 > 状态与主操作 > 进度、说明与历史。

## 令牌

- 颜色、字体、间距、圆角、阴影和动效以 `packages/design-tokens/src/tokens.css` 为唯一首选来源。
- 正文使用系统中文无衬线字体；项目名称与成果可使用 `--nextone-font-serif`，操作控件不使用衬线字体。
- 外层容器使用小到中圆角；内层列表优先分隔线，不重复套卡片。
- 阴影只表示浮层、悬浮或明确抬升层级；常驻内容以背景和边框区分。
- 动效只使用 `transform`、`opacity` 或颜色变化，并遵循 `prefers-reduced-motion`。

## 响应式结构

- 桌面：72px 导航栏；项目总览使用受控内容宽度；项目看板为三列执行区加任务检查器。
- 平板：任务检查器移到执行区之后，看板改为纵向状态段，不制造页面级横向滚动。
- 手机：底部一级导航；任务卡片点击直接打开详情抽屉；状态段纵向排列，主操作始终可见。

## 交互与状态

- 主操作默认可见；次要操作可渐进披露，但键盘聚焦与触屏设备必须可见。
- 拖拽只是快捷路径，所有状态变更必须保留按钮路径。
- 加载、空、错误、离线、同步中、同步失败、成功和禁用状态沿用同一套表面与文案层级。
- 任务状态必须同时使用文字；颜色只作辅助。

## 可访问性与验收

- 桌面键盘可到达导航、项目、任务与主要状态操作；提供“跳到主要内容”。
- 焦点清晰，移动端触控目标不小于 44px；表单使用可见标签或明确的无障碍名称。
- 验收视口：1280×800、390×844；项目宽屏看板补查 1440px。
- 不允许页面级水平溢出、导航遮挡、核心操作只在悬浮时出现或只依赖拖拽。
