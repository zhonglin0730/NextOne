# NextOne M9 Daily Loop 验收指南

## 1. 本阶段目标

M9 把 NextOne 的日常使用闭环补齐为：

```text
今日规划 → 单任务推进 → 每日收尾
```

本阶段不接入外部日历，不引入番茄钟或付费服务。

## 2. 今日规划

前置条件：

- 当天没有已安排任务；
- 收件箱或看板中至少有一个可选任务；

验收步骤：

1. 打开 `/today`；
2. 确认页面不会用弹窗阻断进入，点击空状态中的“规划今天”；
3. 选择一至三项任务；
4. 确认第四项无法继续选中；
5. 确认当前页面直接展示所选任务的预计投入；
6. 点击“安排 N 项到今天”；
7. 确认任务进入今日承诺，但不会自动切换为 DOING。

“取消”应立即关闭对话框，且不会阻断 Today 页面。用户可从今日承诺空状态再次打开。

## 3. 今日容量

默认每日专注容量为 240 分钟，可在“设置 → 任务规则”修改。

验收内容：

- 相同任务同时存在于 Today 与 DOING 时只累计一次；
- 无预估任务显示“尚未预估”数量；
- 存在未预估任务时先显示“负荷待确认”，不提前判断宽松；
- 宽松、合适、偏满和超载状态随预计总时长变化；
- 超载只提出取舍建议，不自动移除任务。

## 4. Zen 模式

1. 将一个任务切换为 DOING；
2. 在“正在进行”中点击“专注”；
3. 确认侧栏、候选任务和其他页面操作全部隐藏；
4. 确认页面只保留任务标题、备注或下一步提示、预估时长、暂停、完成和退出；
5. 按 Escape，确认退出 Zen 模式；
6. 再次进入，分别验证“暂停”和“完成”会更新任务状态并关闭 Zen 模式。

## 5. 自动化验证

```bash
pnpm --filter @nextone/web check
pnpm --filter @nextone/web test
pnpm --filter @nextone/web build
```

容量计算的回归测试位于 `apps/web/src/today/capacity.test.ts`。

## 6. 已知边界

- 今日规划不会自动弹出，也不保存额外的设备级提示状态；
- DailyPlan 和所选焦点仍通过现有 Outbox 正常同步；
- M9 不提供日历时间轴、自动排程、倒计时或专注统计；
- Android 本阶段继续使用现有 Today 流程，后续再将仪式化界面下沉到原生端。
